# Code of Conduct

This project adopts the [Contributor Covenant v2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, be constructive, assume good faith, and keep discussions
about the work. Harassment or discrimination of any kind is not tolerated.

Report concerns to the repository owner via GitHub issues (or privately via the
email on the owner's GitHub profile). Reports are handled confidentially.
